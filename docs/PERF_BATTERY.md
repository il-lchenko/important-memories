# Энергопотребление: замеры и результаты

Метод: headless Chromium (CDP `Performance.getMetrics`), окно 390x800, 10-20 секунд простоя, метрики TaskDuration (процессорное время главного потока), LayoutCount, RecalcStyleCount.

## 22.10.2026, PWA
| Страница | До | После |
|---|---|---|
| Лендинг `about.html` | 0.463 с CPU за 10 с, 60 перерасчётов вёрстки в секунду | 0.001 с, 0 перерасчётов |
| `/join` | 0.009 с за 20 с | без изменений |
| `/app/login` | 0.015 с за 20 с | без изменений |
| Стена альбома (dev) | 0.001 с за 20 с | без изменений |

Причина на лендинге: две бесконечные анимации внутри SVG-логотипа (`.sparkTw` мерцание, `.glow` «дыхание»). Анимации SVG-элементов идут в главном потоке и гонят вёрстку каждый кадр (на HTML-элементах `transform`/`opacity` идут в композиторе и почти бесплатны). Бесконечные циклы удалены, вводная анимация осталась.
