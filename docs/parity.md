# Паритет: сервер × приложение (Flutter) × веб-версия организатора (PWA)

Правило: сначала сервер, потом Flutter, когда функция устоялась, то PWA. Цены, лимиты и настройки оформления берутся только с сервера (`/pricing`, `/me/entitlements`, `/me/subscription`, `settings` события). После изменений API перегенерировать `guest-pwa/src/api/schema.d.ts` (`backend/scripts/dump_openapi.py` → `openapi-typescript`).
